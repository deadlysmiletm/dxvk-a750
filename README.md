# dxvk-a750

DXVK + gplasync built for Snapdragon 8 Gen 3 (Adreno 750) with the turnip-a750 driver. Packaged as `.wcp` for GameNative / Winlator.

- `dxvk-<ver>.wcp`: x64 + x32 (works in any container)
- `dxvk-<ver>-arm64x.wcp`: native ARM64X for arm64ec containers

Build: Actions > Build DXVK (A750) > Run workflow.
